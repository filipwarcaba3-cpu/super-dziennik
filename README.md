# Super dziennik 4.13.1

Poprawiona wersja funkcji Działu IT.

Najważniejsze poprawki:
- panel IT pokazuje wyraźny znacznik wersji 4.13.1,
- Pracownik IT i Administrator IT mogą dodawać uczniów i nauczycieli w swojej/edytowanej szkole,
- Administrator IT ma panel Historia zmian z przyciskiem Cofnij dla zmian pracowników IT,
- Administrator IT może blokować i odblokowywać pracowników IT,
- zablokowany pracownik IT po zalogowaniu widzi tylko ekran blokady i przycisk Wyloguj się,
- Administrator IT i Pracownik IT mogą zmieniać imię i nazwisko ucznia,
- zachowana obsługa Neon PostgreSQL i DATABASE_URL.
