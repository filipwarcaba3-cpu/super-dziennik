# Super dziennik 4.23

- uczeń może należeć do wielu klas; administrator ma opcję „Dodaj do kolejnej klasy” i może usuwać przypisania,

- zachowana zgodność z dotychczasowym polem klasy głównej i istniejącymi danymi.
